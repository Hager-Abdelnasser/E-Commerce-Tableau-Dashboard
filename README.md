# 📊 E-Commerce Sales & Performance Tableau Dashboard

An interactive Business Intelligence (BI) dashboard built using **Tableau Public** to analyze e-commerce sales performance, product categories, and geographical order distributions.

---

## 🔑 Key Analytical Insights
- **Top Product Categories:** Identified leading product segments driving total revenue and cost metrics.
- **Geographical Distribution:** Visualized order quantities and customer states (`Quantity Per State`) to highlight high-density markets.
- **Price vs. Final Value Analysis:** Examined pricing trends and financial performance across transactions.

---

## 🛠️ Tools & Technologies
- **Data Visualization & BI:** Tableau Public / Tableau Desktop
- **Design & Layout:** Interactive filters, geographic mapping, and structured dashboard containers.
